## نکته مهم SEO
تا زمانی که دامنه واقعی مشخص نشده، canonical عمداً حذف شده تا URL اشتباه به گوگل معرفی نشود. بعد از خرید/اتصال دامنه، canonical و Open Graph را به دامنه واقعی تغییر بده.
